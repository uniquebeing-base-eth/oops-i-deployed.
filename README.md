# Oops, I Deployed.

Build a polished, fun meme-coin website for “Oops, I Deployed” ($DEPLOY), an unofficial meme born on Pools.fun and inspired by the idea of oxdeployer accidentally pressing deploy. The site should feel like a playful onchain meme brand, not a corporate crypto project.

Core visual direction: create an original mascot based on this description: a green duck/penguin-like creature with blank white eyes, a large white beak, a red-and-white DEPLOY cap, green bandana, black oversized hoodie with DEPLOY lettering, sitting in a white unicorn float and pressing a giant red DEPLOY button. Do not use or reproduce any existing third-party PFP exactly; make the mascot an original character for this project. Use the mascot as the main character/brand asset. Use a clean but playful editorial layout, bold oversized typography, rounded cards, subtle motion, and a light/cream background with strong black typography and red/green accent details. Avoid generic neon crypto aesthetics.

Homepage sections:
1. Hero: huge “OOPS, I DEPLOYED.” headline, short line “I think I pressed deploy.”, $DEPLOY badge, primary CTA “Get $DEPLOY” linking to a placeholder Pools.fun URL, secondary CTA “Meet the Deployers” scrolling to NFTs. Feature the mascot prominently.
2. A playful deploy console/button section: a large red DEPLOY button with click animation and humorous copy such as “Do not press this.” Clicking it should trigger a fun visual/message like “too late.” without doing any blockchain transaction.
3. NFT collection section called “THE DEPLOYED” explaining a 10,000 NFT mascot collection. Show collection stats: 10,000 total supply, multiple mascot versions/traits, and a “Mint” CTA. For now make mint interaction a polished UI placeholder that can later be wired to a Base smart contract; do not pretend a real contract exists.
4. NFT gallery with sample mascot cards and varied labels/traits such as Oops, Founder, Night Shift, Poolside, Debugger, Max Deploy, etc. Make the gallery visually rich and easy to expand to 10,000 generated NFTs later.
5. Lore section: short humorous story about the deployer pressing the button and accidentally creating another coin.
6. Simple roadmap framed humorously, e.g. “1. Press deploy. 2. Regret nothing. 3. Deploy more. 4. 10,000 little deployers.”
7. Footer with $DEPLOY, Pools.fun reference, X/Twitter link placeholder, and disclaimer that it is an unofficial community meme and not affiliated with or endorsed by oxdeployer or Pools.fun.

UX requirements: responsive mobile-first design, excellent mobile layout, smooth scrolling, subtle hover/press animations, accessible contrast, sticky compact navbar with logo/name and links Home, NFTs, Lore, and a “Get $DEPLOY” button. Make it feel like a real collectible IP website with strong personality.

Important: do not imply official affiliation with oxdeployer, BNKR, or Pools.fun. The site should clearly say unofficial/community meme. Keep the NFT supply fixed at 10,000 in the UI. Build the actual frontend now, with clean component structure so wallet connection, NFT minting, real gallery metadata, and Pools.fun links can be wired in later.
